# <img src="https://cdn.jsdelivr.net/gh/chocolatey-community/chocolatey-packages@master/icons/womic.svg" width="48" height="48"/> [WO Mic](https://chocolatey.org/packages/womic)

WO Mic can turn your phone to be a microphone for your computer. You do not need to pay a cent to buy a gadget. And it's mobile if you choose wireless transport. Millions of people have installed it and are using it daily for talking, recording, voice remote control and many other activities.

## Features

- Wireless microphone without any cost
- Can be used with any programs on PC just like REAL microphone
- Very short lag
- Easy to configure and use
- Supports auto reconnection when your PC reboots
- Support multiple connection methods: USB, Bluetooth, Wi-Fi, and Wi-Fi direct
- Audio format: 48000 sampling rate, 16 bits per sample, mono channel

## Package Parameters

- None

## Notes

- This package installs the WO Mic client and virtual device driver on Windows
- Requires VC runtime re-distributable (x86) which is automatically installed
- You also need to install the WO Mic app on your phone (Android/iOS)
- If you have security concerns, check the [WO Mic website](https://wolicheng.com/womic/) for more information
