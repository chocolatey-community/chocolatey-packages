# lswitch

Use any key to switch input languages.

## Usage

```powershell
lswitch [keycode]
```

Keycode is optional and defaults to the context menu key (VK_APPS).
Another good candidate is the CapsLock key with a keycode of 20.

## Description

lswitch allows you to use any key to switch input languages. It runs in the background and intercepts the specified key to trigger a language switch.

This is a small, lightweight utility from Haali's Windows utilities collection.

## Files

- `lswitch.exe` - The main executable
